# IBM Jumpstart VR Data Visualization — Proof of Concept

This is a virtual reality proof of concept developed as part of IBM's Jumpstart Technical Challenge. I was responsible for the headset-based VR portion of a four-person team project. The prototype allowed users to interact with statistical data through 3D bar and scatter plots, navigate the environment using VR controls, and explore the visualizations spatially. Another team member later built a flatscreen, multi-user version using the VR environment and code I developed.  That flatscreen portion is not included here.

Since the video has no voice-over, here is a brief description of the action:

- display custom hands with pointer interactions
- fast travel by pointing to the floor and clicking the VR hand controls or walking
- interact with the floating bar graph control to generate a 3D bar chart, based on values entered off screen
- interact with the floating scatterplot button it generates the scatterplot based on values entered off screen
- display window that reflects the values on the Scatterplot

Although the video doesn't show it, there is a wrist menu on the left hand that allows you to exit the environment.  The wrist menu will be evident in the code, should I ever decide to add it to this repository.
